A tiny Node program that writes one line to `entry.txt`: the elevator pitch a city pigeon gives investors for its rooftop crumb-logistics startup, CrumbDash — complete with a literal seed round. The line is stored as a constant, validated at runtime (single line, 1–200 characters), and written exactly with no trailing newline.

## Run it

```sh
node main.ts
```
